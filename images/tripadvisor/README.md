# Tripadvisor source images

The website owner explicitly confirmed permission covering the review excerpts, public reviewer avatars, traveler photos, and public Git storage on 2026-11-06. This records the owner's confirmation; it is not an independent rights certification. Public visibility or attribution alone is not treated as a license.

`SOURCES.json` records the exact observed image URLs, associated review source pages, displayed contributor names, original dimensions, and SHA-256 hashes. `reviewers/` contains the five public avatars available from the listing. Some are Tripadvisor default landscape/avatar imagery, not pictures of the reviewer. No image is invented or assigned to an unrelated person. Sharmilee S had no downloadable public avatar in the inspected source and is not represented by an invented face.

`originals/` contains eight full-size traveler photos attached to reviews by Sam C and Fearless64391184385. Preserve them unchanged. The flood/road image is retained as an original source download but not featured in the marketing gallery. `web/` contains two resized, optimized WebP copies for the live guest gallery; all image content and aspect ratios are retained. Captions credit the displayed contributor and link to the specific review where the image was found.

All live image URLs are local GitHub Pages paths. There is no hotlinking to Tripadvisor, scraper, scheduled refresh, API key, or production model call.

Maintain the source inventory and permission record whenever adding or replacing an image. If permission is withdrawn or a source association is disputed, remove the affected published asset and card promptly.
